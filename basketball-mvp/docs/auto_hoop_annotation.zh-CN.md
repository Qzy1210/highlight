# 自动篮框检测：标注规范（YOLO）

本规范用于训练“篮框候选检测模型”（单类 `hoop`）。

## 1. 标注目标

- 类别仅 1 类：`hoop`（篮框）。
- 标注对象是“篮圈本体”，不包含整块篮板。

## 2. 框选规则

1. 框住完整篮圈外沿，左右尽量对称。
2. 上下边界可包含少量篮网（建议不超过篮圈直径的 `1/3`）。
3. 遮挡时仍按“可见部分推断完整位置”进行框选。
4. 篮圈极小或严重模糊时可跳过（避免脏标签）。

## 3. 负样本与难例

- 负样本（无篮框）建议占总帧数 `15%~25%`。
- 难例建议单独抽样并保证覆盖：
  - 逆光、夜间、低清晰度、运动模糊。
  - 多人遮挡、远景小目标、偏角度篮筐。

## 4. 数据划分建议

- `train/val/test = 8:1:1`。
- 同一段视频的相邻帧不要跨集合，避免数据泄漏。
- 首版建议样本量（已标注帧）：
  - train: `800~1500`
  - val: `100~200`
  - test: `100~200`

## 5. 目录结构（YOLO 格式）

```text
training/hoop_detector/datasets/hoop_v1/
├─ images/
│  ├─ train/
│  ├─ val/
│  └─ test/
└─ labels/
   ├─ train/
   ├─ val/
   └─ test/
```

标签格式（每行）：

```text
<class_id> <x_center> <y_center> <width> <height>
```

- 全部是归一化坐标（0~1）。
- 单类时 `class_id=0`。

## 6. 质检清单

1. 是否存在漏标（图中有篮框但无标签）。
2. 是否存在错标（把篮板、广告框等标成篮框）。
3. 框大小是否一致（不要有“有时圈很紧，有时很松”）。
4. 小目标样本占比是否足够（至少 25%）。
